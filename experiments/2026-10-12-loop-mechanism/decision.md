# Decision

Prepared for an isolated mechanism canary; not promoted and not yet run.

The temporary native hook passed independent offline source review and twelve
focused wiring tests. The packaging stage checks exact profile preservation,
the seven accepted overlay hashes, real r6f lock/source-manifest consistency,
unchanged runtime Python, fixture scope, privacy and the repository's original
local doctor. These are preparation checks, not native recovery evidence.

Actual retry/parser/SSE, six-image preservation, HTTP disconnect, Python
double-cancel, scheduler idle and measured overhead remain required. Real-loop
detection and model-quality evaluation remain a later separate experiment.
No performance gain or lossless-generation claim is made.
The publication review identified a deployment-plan gap: owner-fork sync needs
an explicit stopped-state origin transition, and the experimental control does
not restore original Git/profile/mount-source state. The revised runbook adds
private timestamped per-rank backups, an isolated published owner controller,
a retained original rollback controller, guarded origin changes, and exact
original restoration before readmission. Only documentation changed; runtime,
profiles, fixtures, immutable plans and helpers remain byte-identical. Historical
offline checks are retained separately from the documentation-revision checks.
No remote change, publication or cluster operation has been performed.
